# Ветвление и отсечения на графах

Набор рассчитан на один-два семинара. Задачи расположены по возрастанию
сложности реализации. Во всех задачах вершины нумеруются от 1 до `n`, граф
неориентированный, петель нет, а кратные рёбра разрешены. Повторное ребро не
меняет условие конфликта и при чтении просто устанавливает уже установленный
бит.

Ограничения подобраны так, чтобы множество вершин и списки смежности можно
было хранить в `uint64_t`. При этом полный перебор всех `2^n` подмножеств не
считается предполагаемым решением: цель семинара — реализовать ветвление,
отсечения и эвристику выбора следующей вершины.

## 1. Закрытие дорог

В стране есть `n` городов и `m` двусторонних дорог. Требуется назначить
дежурных не более чем в `k` городах так, чтобы у каждой дороги хотя бы в одном
из её концов был дежурный. Определите, возможно ли это.

Это задача о вершинном покрытии. Она удобна для первого знакомства с методом:
любая непокрытая дорога сразу даёт две ветви.

Ограничения: `1 <= n <= 60`, `0 <= k <= n`.

Формат ввода:

```text
n m k
u1 v1
...
um vm
```

Выведите `YES` или `NO`.

Файлы:

- `01_vertex_cover.cpp` — решение;
- `01_vertex_cover.txt` — пример ввода;
- `01_vertex_cover.expected.txt` — ожидаемый вывод.

## 2. Экспедиция

Для экспедиции рассматриваются `n` кандидатов. Некоторые пары конфликтуют и
не могут участвовать одновременно. Определите, можно ли выбрать ровно `k`
кандидатов без конфликтующих пар.

Это задача о независимом множестве заданного размера. Студентам нужно перейти
от ветвления по ребру к ветвлению «взять вершину или отказаться от неё» и
научиться обновлять маску допустимых кандидатов.

Ограничения: `1 <= n < 50`, `0 <= k <= n`.

Формат ввода:

```text
n m k
u1 v1
...
um vm
```

Выведите `YES` или `NO`.

Файлы:

- `02_independent_set.cpp` — решение;
- `02_independent_set.txt` — пример ввода;
- `02_independent_set.expected.txt` — ожидаемый вывод.

## 3. Лучший состав экспедиции

Для тех же данных найдите не просто ответ на вопрос существования, а
независимое множество максимального размера.

Здесь появляется глобально лучший найденный ответ, верхняя оценка для
незавершённой ветви и восстановление выбранных вершин.

Ограничение: `1 <= n < 50`.

Формат ввода:

```text
n m
u1 v1
...
um vm
```

В первой строке выведите максимальное количество кандидатов. Во второй строке
выведите их номера в возрастающем порядке. Если оптимальных множеств несколько,
разрешается вывести любое.

Файлы:

- `03_maximum_independent_set.cpp` — решение;
- `03_maximum_independent_set.txt` — пример ввода;
- `03_maximum_independent_set.expected.txt` — ожидаемый вывод.

## 4. Сборка модулей

Есть `n` программных модулей. У модуля `i` есть полезность `wi`. Некоторые пары
модулей несовместимы. Требуется выбрать ровно `k` попарно совместимых модулей с
максимальной суммарной полезностью.

Это взвешенная версия независимого множества. Кроме количества оставшихся
вершин, для отсечения потребуется численная верхняя оценка результата ветви.

Ограничения: `1 <= n < 50`, `0 <= k <= n`,
`1 <= wi <= 10^9`.

Формат ввода:

```text
n m k
w1 w2 ... wn
u1 v1
...
um vm
```

Если выбрать `k` модулей невозможно, выведите `IMPOSSIBLE`. Иначе в первой
строке выведите максимальную суммарную полезность, а во второй — номера
выбранных модулей в возрастающем порядке. При нескольких оптимальных ответах
разрешается вывести любой.

Файлы:

- `04_weighted_modules.cpp` — решение;
- `04_weighted_modules.txt` — пример ввода;
- `04_weighted_modules.expected.txt` — ожидаемый вывод.

## Сборка и запуск

Все решения совместимы с C++17. Например, первую задачу можно проверить так:

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic \
  01_vertex_cover.cpp -o 01_vertex_cover
./01_vertex_cover < 01_vertex_cover.txt
```

Результат должен совпасть с `01_vertex_cover.expected.txt`. Остальные задачи
проверяются аналогично. Если установленный `clang++` поддерживает C++20, можно
заменить `-std=c++17` на `-std=c++20` без изменения исходников.

Основные идеи и обоснование отсечений находятся в `solutions.md`.
