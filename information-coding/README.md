# Кодирование информации

Набор рассчитан на два семинара. Его цель — познакомиться с исправлением
одиночной ошибки кодом Хэмминга и с двумя способами сжатия без потерь: кодом
Хаффмана и алгоритмом LZW. На первом семинаре рекомендуется разобрать задачи 1
и 2, на втором — закончить задачу 2 и перейти к задаче 3.

Во всех задачах позиции в строках нумеруются слева направо. Если отдельно не
сказано иное, нумерация начинается с нуля. Для кода Хэмминга используется
принятая в его определении нумерация с единицы.

Эталонные решения написаны на C++17. Входные данные корректны и удовлетворяют
указанным ограничениям. Перебирать возможные исходные сообщения не требуется.

## 1. Исправление посылки

Дан полный двоичный код Хэмминга длины `n = 2^r - 1`. Позиции кодового слова
нумеруются от `1` до `n` слева направо. Позиции `1, 2, 4, 8, ...` содержат
проверочные биты. Остальные позиции содержат информационные биты.

Используется проверка на чётность. Для каждого `j` от `0` до `r - 1`
количество единиц на позициях, у которых бит `j` в двоичной записи номера равен
единице, должно быть чётным. Проверочная позиция `2^j` также входит в эту
группу.

Полученное слово отличается от некоторого корректного кодового слова не более
чем в одной позиции. Найдите позицию ошибки, исправьте слово и восстановите
информационные биты. Первый символ строки соответствует позиции `1`. Если
ошибки нет, её позиция считается равной `0`.

Ограничения:

- `2 <= r <= 20`;
- длина входной строки равна `2^r - 1`;
- строка состоит только из символов `0` и `1`.

Формат ввода:

```text
r
received
```

Формат вывода:

```text
error_position
corrected
data
```

В первой строке выведите номер ошибочной позиции или `0`, если ошибки нет. Во
второй строке выведите исправленное кодовое слово. В третьей строке выведите
информационные биты слева направо, пропустив позиции, являющиеся степенями
двойки.

Ответ определяется однозначно благодаря условию о не более чем одной ошибке.

Учебная цель задачи — разобраться в расположении проверочных битов, построении
синдрома и исправлении одиночной ошибки. Вспомогательные приёмы — нумерация с
единицы, проверка степени двойки и побитовый `XOR`.

Файлы:

- `01_hamming.cpp` — решение;
- `01_hamming.txt` — пример ввода;
- `01_hamming.expected.txt` — ожидаемый вывод.

## 2. Код Хаффмана

Дана непустая строка из заглавных латинских букв. Постройте для встретившихся
букв двоичный код Хаффмана и закодируйте строку.

Сначала для каждой буквы создаётся дерево из одной вершины. Его вес равен числу
вхождений буквы в строку. Затем, пока деревьев больше одного, два первых дерева
в следующем порядке объединяются в новое дерево:

1. Меньший вес даёт больший приоритет.
2. При равных весах больший приоритет имеет дерево с меньшей
   лексикографически буквой среди всех его листьев.

Первое выбранное дерево становится левым сыном, а ребру к нему соответствует
бит `0`. Второе становится правым сыном, а ребру к нему соответствует бит `1`.
Вес нового дерева равен сумме весов сыновей. Активные деревья не имеют общих
букв, поэтому описанное сравнение всегда однозначно.

Код буквы — последовательность битов на пути от корня до соответствующего
листа. Если во входной строке встречается только одна различная буква, её код
равен `0`.

Ограничения:

- `1 <= n <= 200000`;
- длина строки равна `n`;
- строка состоит только из букв `A`–`Z`.

Формат ввода:

```text
n
s
```

Формат вывода:

В первой строке выведите количество различных букв `k`. Затем выведите `k`
строк с буквой и её кодом через пробел. Буквы должны идти в алфавитном порядке.
В последней строке выведите закодированную строку без пробелов.

Описанные правила полностью определяют дерево, поэтому допустимой
неоднозначности ответа нет.

Учебная цель задачи — построить таблицу частот, реализовать жадное объединение
деревьев с помощью очереди с приоритетом, восстановить коды обходом дерева и
применить их для кодирования строки.

Файлы:

- `02_huffman.cpp` — решение;
- `02_huffman.txt` — пример ввода;
- `02_huffman.expected.txt` — ожидаемый вывод.

## 3. LZW-кодирование

Дана непустая строка `s` из заглавных латинских букв. Требуется закодировать её
алгоритмом LZW.

В начальный словарь входят все односимвольные строки: `A` имеет код `0`, `B` —
код `1`, ..., `Z` — код `25`. Следующий добавленный элемент получает код `26`,
затем `27` и так далее. Словарь не очищается и не имеет ограничения размера.

Кодирование выполняется слева направо. На каждом шаге выбирается самый длинный
непустой префикс ещё не обработанной части строки, который уже находится в
словаре. Его код добавляется в ответ. Если после выбранного префикса остался
символ `c`, в словарь добавляется строка из выбранного префикса и символа `c`.
После этого обработка продолжается с символа `c`.

Если выбранный префикс заканчивается вместе со строкой, его код добавляется в
ответ, а новый элемент в словарь не добавляется. Упаковывать коды в биты не
нужно: каждый код выводится обычным десятичным числом.

Ограничения:

- `1 <= |s| <= 200000`;
- строка `s` состоит только из букв `A`–`Z`.

Формат ввода:

```text
s
```

Формат вывода:

В первой строке выведите количество кодов `k`. Во второй строке выведите `k`
кодов в порядке их получения, разделяя соседние числа одним пробелом.

При указанных правилах словарь и последовательность кодов определяются
однозначно.

Учебная цель задачи — научиться поддерживать динамический словарь фраз LZW и
представлять продолжение фразы парой «код известной фразы, следующий символ».
Такое представление позволяет не хранить и не сравнивать длинные строки.

Файлы:

- `03_lzw.cpp` — решение;
- `03_lzw.txt` — пример ввода;
- `03_lzw.expected.txt` — ожидаемый вывод.

## Сборка и запуск

Все решения совместимы с C++17. Например, первую задачу можно проверить так:

```sh
clang++ -std=c++17 -O2 -Wall -Wextra -Wpedantic \
  01_hamming.cpp -o 01_hamming
./01_hamming < 01_hamming.txt
```

Результат должен совпасть с `01_hamming.expected.txt`. Остальные задачи
проверяются аналогично. Идеи, доказательства корректности и разбор типичных
ошибок находятся в `solutions.md`.
